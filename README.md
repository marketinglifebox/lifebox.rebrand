# Clube Life — site do programa de pontos do Lifebox

Esta branch guarda só os arquivos publicados do site do Clube Life (a página que o cliente vê).

- Publicado na Vercel: time LifeBox, projeto `clube-life` (https://clube-life-life-box.vercel.app)
- Na hora do build, a Vercel baixa esta branch e publica o que está aqui.
- Para atualizar: troque os arquivos desta branch e faça um novo deploy do projeto `clube-life`.
- Enquanto o programa não lança, a página tem `noindex` (não aparece no Google). Tirar no lançamento.
